漢字 en la pantalla de bloqueo

Un kanji con su lectura y significado, que va cambiando solo a lo largo del día. Se hace con la app gratuita Scriptable; se configura una vez (unos 3 minutos).

1 · Instala Scriptable

Abrir Scriptable en el App Store

2 · Copia el código

// Kanji widget
const u = "https://deliciassaulmoreno-ghub.github.io/jlpt-app/kanji/widget.js";
const fm = FileManager.local();
const p = fm.joinPath(fm.documentsDirectory(), "kanji-widget-code.js");
let code;
try { const r = new Request(u); r.timeoutInterval = 15; code = await r.loadString(); if (code.includes("ListWidget")) fm.writeString(p, code); else throw 0; }
catch (e) { code = fm.readString(p); }
await eval("(async()=>{" + code + "\n})()");

3 · Crea el script

  1. Abre Scriptable y pulsa + (arriba a la derecha).
  2. Mantén pulsado en la zona vacía y elige Pegar.
  3. Toca el título de arriba y llámalo Kanji. Pulsa Done.
  4. Tócalo una vez para probar: debe aparecer un kanji.

4 · Ponlo en la pantalla de bloqueo

  1. Con el iPhone bloqueado, mantén pulsada la pantalla → Personalizar → Pantalla de bloqueo.
  2. Toca la zona de widgets (debajo de la hora) → busca Scriptable → elige el widget rectangular.
  3. Toca el widget recién añadido → en Script elige Kanji.
  4. Opcional, en Parameter: los niveles que quieres ver, por ejemplo N1 o N2 N1. Vacío = todos.
  5. Pulsa OK.

Tamaños

iOS solo permite estos tamaños; en todos se elige el script Kanji.

  1. 1×1 (bloqueo, circular): kanji y su primera lectura.
  2. 2×1 (bloqueo, rectangular): kanji, lecturas y significado.
  3. 4×1 (bloqueo): pon dos rectangulares seguidos. En el segundo escribe ej en Parameter (con niveles: N1 ej): muestra la palabra de ejemplo del mismo kanji.
  4. Línea sobre la hora (bloqueo): kanji, lectura y significado en una línea.
  5. 2×2 (inicio, pequeño): kanji, lecturas y significado.
  6. 4×2 (inicio, mediano): además, la palabra de ejemplo.
  7. 4×4 (inicio, grande): además, el truco para recordarlo.

La pantalla de bloqueo solo tiene una fila de widgets, así que 3×2 y 4×2 no existen ahí; el 4×2 va en la pantalla de inicio (mantén pulsado un hueco → Editar → Añadir widget → Scriptable).

A tener en cuenta

El kanji cambia cada 20 minutos, cuando iOS refresca el widget (a veces tarda más; no se puede forzar). Todos los widgets con los mismos niveles muestran el mismo kanji. Sale al azar del nivel elegido: el widget no puede leer tu progreso de la app. Funciona sin conexión tras la primera carga.
